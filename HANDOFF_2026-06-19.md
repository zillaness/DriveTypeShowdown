### Custom map editor — how it works (so you can extend it)
- **Entry:** RoboRumble → ARENA gallery → the green **"+ NEW MAP"** tile (`bbMapTiles` appends custom ids + `'new'`). Custom tiles show **✎ edit / 🗑 delete**.
- **Screen:** `phase==='p2mapedit'`, drawn by `drawMapEditor()`, state in `let mapEd={id,name,obs,haz,pup,tool,drag,undo,_touch}`.
- **Tools** (`MAP_TOOLS`): WALL + PIT = drag-to-draw rects; SAW + PICKUP = click to place; ERASE = click to remove topmost (`mapEditEraseAt`). Plus name field, CLEAR, UNDO (↶ / Z key, 40-deep `mapEd.undo` via `mapEdPush()`), **SAVE & USE**, and **📤 SHARE** (export).
- **Input:** driven by its OWN mousedown/move/up (`mapEditDown/Move/Up`) AND touchstart/move/end (tracks `mapEd._touch`); the `click` dispatcher early-returns for `p2mapedit`; mousedown sets `_bbDragSuppressClick` so a SAVE/BACK phase-change doesn't fall through.
- **Storage/resolve:** `customMaps` (localStorage key `frcds_maps_v1`), `saveCustomMaps()`, `customMapById()`, `bbMapObj()` resolves the ARENA setting → built-in index | `'rand'` (rolls over built-ins+custom) | custom id. RoboRumble match-start uses `bbMapObj()`; **Tank Fight stays built-in-only** (lines ~3305).
- **Share codes:** `mapToCode(m)` → `DSMAP1:`+base64(JSON); `mapFromCode(code)` validates + rejects garbage. 📥 IMPORT MAP button on the gallery (`mapImport()` via prompt). Workshop-ready JSON.
- **Tests:** `harness/tests/smoke57.js` (battlebots P1, now **515 asserts**) — editor create→draw→save→resolve→gallery→load, share round-trip, undo. `smoke52.js` gallery-count assert was updated for the NEW tile.

**The full LOCKED design is in `OVERNIGHT_PLAN.md` → "🏆 TOURNAMENT v2 — LOCKED DESIGN (Sam, 2026-06-19)".** Read it. Summary of the decisions Sam made this thread:
- **Two formats (a setting):** KEEP the existing **single-elim** (party, ≤16) AND add **double-elim "FRC mode"** (≤8, losers' bracket + **best-of-3 grand final**).

- **One mode for the whole bracket; the MAP varies per match.** Map-pick rule: **higher seed picks** during the bracket; **winners-bracket team picks at the grand final**; optional **open/group-pick with a countdown that auto-randomizes.**
