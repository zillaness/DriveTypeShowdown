## ⚠️ Gotchas (carried forward)
- **Mock canvas is a no-op** → a real-browser-only render crash (e.g. the v5.1.270
  FFA null-drive) only shows if a test **calls the draw fn** (`drawBB()`/
  `bbDrawMines()`). New draw paths need a no-throw test that actually draws.
- **smoke57's body is an eval'd template string** — no apostrophes in `ok('…')`
  labels (breaks parsing).
- `battery.sh` exit code is trustworthy **only after** `extract.sh`.
- HTML has **very long base64 lines** — `Read` a small range or Grep with context;
  edit via unique strings.
- A blast's hit **location** matters: it's classified front/side/rear vs the victim's
  heading, and **side hits drain MOBILITY not HP** — position test foes at the rear
  to assert HP damage (bit the v5.1.297 timed-mine test).
